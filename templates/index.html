Vehicles · Autonomy

My Self-Driving G-Wagon

A 2011 G55 AMG fitted to run comma's openpilot driving models on its own cameras. Both CAN buses are decoded (131 signals) by a Rust gateway on a Raspberry Pi 5. The Bosch engine ECU is patched to accept a torque request at 50 Hz, the transmission runs open-source firmware, and a Jetson Orin NX runs the driving model at 20 Hz.

Steering has no motor yet, so I test models in closed loop first: every comma release since December 2025 is replayed against the truck's drives and rolled out in a learned G55 dynamics simulator.

Coding agents · Infrastructure

Longhouse

Remote control for coding agents. Claude Code, Codex, Cursor and OpenCode sessions keep running on your machines after you close the laptop, and you can check on them, answer them or start new ones from a phone.

Every session is archived to SQLite so past work stays searchable. Rust engine, FastAPI server, Swift apps.
